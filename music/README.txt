ПАПКА МУЗЫКИ ДЛЯ ПРИЛОЖЕНИЯ MTB SKILLS PRO
=============================================

Как добавить свою музыку (самый простой способ):
1. Возьми свои музыкальные файлы (mp3, m4a, ogg, wav или webm).
2. Положи их прямо в эту папку music/.
3. Назови их: track1.mp3, track2.mp3, track3.mp3 ... (до 20 штук; расширение любое из списка выше).
4. Загрузи изменения на GitHub (или попроси меня) — приложение обновится само.

Как это работает:
- Плеер сам находит файлы track1..track20 и играет их по очереди, по кругу.
- Если в папке нет музыки — плеер не показывается вообще.
- После того как трек закончился — автоматически включается следующий.
- Можно также вписать свои треки вручную в файл songs.js (любые имена).

Названия треков в плеере = имя файла без расширения (track1, track2, ...).
Чтобы сменить музыку — замени файлы на другие (с теми же именами track1, track2, ...).
